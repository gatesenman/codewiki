# Initialize CodeWiki / 初始化 CodeWiki

Run **CodeWiki: Initialize** from the Command Palette (`Ctrl+Shift+P`).

It will:
1. Detect the `codewiki` CLI (or help you configure `codewiki.cliPath`).
2. Write `.vscode/mcp.json` so any MCP-capable code agent can consume CodeWiki.
3. Index your project and verify everything works.

---

从命令面板（`Ctrl+Shift+P`）运行 **CodeWiki: 初始化**。它会：
1. 检测 `codewiki` CLI（或引导你设置 `codewiki.cliPath`）。
2. 写入 `.vscode/mcp.json`，让支持 MCP 的 code agent 消费 CodeWiki。
3. 索引项目并验证可用。
