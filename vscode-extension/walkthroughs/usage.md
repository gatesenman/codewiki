# Use the Usage Panel / 使用「使用面板」

Click the **CodeWiki** icon in the Activity Bar (left edge) to open the sidebar, then use the **Usage Panel** — a grid of one-click buttons for every feature: initialize, index, health check, security scan, pattern detection, semantic search, ask, pre-check, impact, relations, export, settings, status.

You never have to memorize a command.

---

点击活动栏（最左侧）的 **CodeWiki** 图标打开侧边栏，使用 **使用面板** —— 一个覆盖所有功能的一键按钮网格：初始化、索引、健康检查、安全扫描、模式检测、语义搜索、提问、修改前预检、影响分析、关系、导出、设置、状态。

无需记忆任何命令。
